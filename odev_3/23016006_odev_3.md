  Variables and Data Types: Bu başlıkta inceleyeceğimiz data tipleri şunlandır; int, float, string ve bool.  
int data tipi tam sayıları ifade eder. (2, -5)   
float ondalıklı sayıları ifade eder.  (1.63, 36.5)  
str metinsel ifadelerdir. ( Name = "Yoda Yazılım" )  
bool mantık veri tipidir. Yalnızca False ya da True değeri alabilir.  

  int() fonksiyonu ile data tipi tam sayıya çevirilir.
  float() fonksiyonu ile data tipi ondalıklı sayıya çevirilir.  
  str() fonksiyonu ile data tipi metne çevirilir.  

  input() fonksiyonu kullanıcıdan veri almak için kullanılır. Bu fonksiyon her zaman str veri tipi döndürür. Girilen ifade yukarıdaki int() gibi fonksiyonlarla istenen data tipine çevrilir.
