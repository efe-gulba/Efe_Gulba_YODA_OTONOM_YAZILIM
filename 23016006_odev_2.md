Git ve Github Temel Kavramları  

Repository: Kullancılar tarafından oluşturulan bir depodur. Bu depoda kullanıcılar projelerine ait dosyalarını, kodlarını ve yaptıkları değişiklikleri saklarlar. Projenin kim tarafından hangi değişikliklerin yapıldığını takip etmede bu depo önemlidir.  
<img width="550" height="300" alt="image" src="https://github.com/user-attachments/assets/cb745335-8451-46ce-8d77-279cddf410ec" />  
Bu görselde test amaçlı Github üzerinde bir repository oluşturulmuştur.  

Commit: Proje üzerinde yapılan değişikliklerin kaydedilmesine denir. Her commit sonucunda açıklayıcı bir mesaj eklenir. Bu sayede projede yapılan değişikliklerin takibi kolay olur.  
<img width="550" height="300" alt="image" src="https://github.com/user-attachments/assets/f3a103a9-e119-4580-b9b8-3562efd3cdfb" />  
Burada proje üzerinde yapılan değişiklik mesaj ile commit edilmiştir.

Push: Proje üzerinde yapılan değişiklikleri bilgisayardan depoya gönderme işlemine denir. Bu sayede Github üzerinde bilgisayarda yapılan değişiklikleri saklayabiliriz.  

Pull: Depoda bulunan güncel değişikliklerin bilgisayara aktarılmasına denir. Bu sayede ortak projeye yeni kod eklenmesi durumunda kullanıcı kendi bilgisayarına yapılan değişiklikleri çekebilir.  

<img width="550" height="300" alt="image" src="https://github.com/user-attachments/assets/5b606597-7e7f-407c-9e3a-390abefeebe8" />   

Burada yukarıda commit edilen yeniliğin push komutuyla githuba aktarılması ve pull komutunun nasıl yapılacağı gösterilmiştir.  

Branch: Ana kısımda yapılan projeyi etkilemeden güncellemeler yapmak ve değişiklikleri denemek için dallar oluşturulur. Bu dallara branch denir.  

<img width="1139" height="134" alt="image" src="https://github.com/user-attachments/assets/0fe0eaa3-5c7d-41fc-bf29-21e04277281f" />  

Test deposunda bir branch oluşturulmuştur.  

Stage: Değişikliklerin doğrudan kaydedilmeyip commit için hazırlanmasına denir. Yapılan değişikliği stage alanına alarak commit edebilirim.  

Merge: Farkli branch'lerde yapılan değişiklikleri birleştirerek main de toplanmasına merge denir. Branch'lerde yapılan güncellemeler pull komutuyla main'e alınır. Yukarıda test amaçlı oluşturduğum branch'i pull komutuyla main'de birleştirdim.
